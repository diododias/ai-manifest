# Manifestos para Escalar Squads com IA

Este repositório reúne manifestos, guias e boas práticas para ajudar times e organizações a escalar squads com foco em adesão e produtividade no uso de Inteligência Artificial.

## Objetivo

Compartilhar conhecimento, experiências e frameworks que auxiliem na adoção eficiente de IA em squads, promovendo cultura, processos e resultados consistentes.

## Conteúdo

- **Manifestos**: Princípios e diretrizes para squads AI-first
- **Fluxos de Trabalho**: Modelos de processos para adoção e evolução de IA
- **Boas Práticas**: Recomendações para maximizar produtividade e engajamento
- **Casos de Uso**: Exemplos reais de squads que escalaram com IA

## Como Contribuir

1. Faça um fork deste repositório
2. Crie um branch para sua contribuição
3. Adicione seu manifesto, guia ou exemplo
4. Abra um Pull Request
