# Wiki do Agent Team

> Material educativo para aprender a operar o Agent Team: um núcleo humano de **Product Manager, UX e Tech Lead** que dirige agentes especializados do backlog à produção, sem perder controle, evidência ou rastreabilidade.

Bem-vindo. Esta wiki foi escrita para **ensinar**, não apenas para documentar. Cada seção parte de "por que isto existe", mostra "como funciona" e termina em "como você usa no dia a dia". Se você está chegando agora, leia na ordem. Se já conhece o modelo, use o índice para saltar direto ao que precisa.

## Como esta wiki é organizada

Cada macroassunto é uma pasta com duas camadas de leitura. A **pista rápida** (`TLDR.md`) resume a seção inteira em poucos minutos — começo, meio e fim — e aponta para as páginas de detalhe. As **páginas de detalhe** aprofundam um subassunto por vez. Você nunca precisa ler tudo para decidir se algo é relevante: comece pelo TLDR e desça só onde o assunto interessar.

```text
macroAssunto/
├── TLDR.md          # pista rápida: resumo da seção + para onde ir
└── subAssunto.md    # detalhe de um tema específico
```

## As três ideias que sustentam tudo

Se você guardar apenas três frases desta wiki, guarde estas. Elas reaparecem em cada seção, aplicadas a um contexto diferente.

Primeiro: **quem propõe uma mudança não é quem a aprova**. A crítica sempre vem de uma instância independente de quem produziu o artefato. Segundo: **aprovação exige evidência explícita, e silêncio nunca equivale a aprovação**. Nenhuma passagem entre fases acontece por conversa — passa por artefatos versionados com owner, gate e evidência. Terceiro: **a autonomia só cresce quando gates e métricas demonstram que é seguro** — nunca por otimismo.

## Antes de escrever ou editar

Ao contribuir, atualize primeiro a pista rápida da seção, depois as páginas de detalhe, e preserve os links relativos entre páginas.
