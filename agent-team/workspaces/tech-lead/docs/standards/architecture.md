# Padrão de arquitetura

- Registre decisões relevantes em ADRs dentro do projeto afetado.
- Declare contratos entre sistemas e seus responsáveis.
- Prefira mudanças incrementais e reversíveis.
- Mantenha regras de negócio independentes de detalhes de infraestrutura.
- Não promova uma regra específica de projeto a padrão global sem evidência de reuso.
